# CineVerse Web

A static, PC-friendly web client for the CineVerse catalogue.

- Browse, search and view details for movies & series using the Cinemeta (IMDb) catalogue.
- Playback is provided by embedded providers (VidFast, VidLink, 2Embed).
- Hosted on GitHub Pages: https://riju2007123.github.io/cineverse-web/

## Run locally

```sh
python -m http.server 8080
```

Then open http://localhost:8080.
